# 任意の機能（初回は無効）

ここにあるものは、**`.env` の `COMPOSE_PROFILES` に名前を足したときだけ**本体の
`app/config/eccube/packages/` へマージされる（entrypoint が起動時に判断する）。
`packages/` に置いたものは常にマージされるので、切り替えたいものはこちらへ置く。

| ディレクトリ | プロファイル | 起動するサービス | 効くこと |
|---|---|---|---|
| `redis/` | `redis` | `redis`, `redis-session` | アプリキャッシュとセッションを Redis に |
| `messenger/` | `messenger` | `worker` | メール送信を非同期に（DB キュー） |

**サービスの起動と設定の投入は同じスイッチで決まる。** 別々にすると「設定だけ入って
Redis が居ない → 全ページ 500」「worker だけ居なくてメールが DB に溜まり続ける」の
どちらかが黙って起きる。

外すと、entrypoint が該当ファイルを `packages/` から消す（マージは足すだけなので、
消さないと前回の設定が残る）。
